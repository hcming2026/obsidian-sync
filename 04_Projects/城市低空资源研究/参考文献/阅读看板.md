# 阅读看板

> 阅读状态在论文笔记 frontmatter 的 `status` 字段维护（`未读` / `精读中` / `已精读` / `待复核`），本看板自动更新。
> 需要 Dataview 插件（已安装）；若看板不显示，重启 Obsidian 或按 Ctrl+P → Reload app without saving。

## 状态统计

```dataview
TABLE WITHOUT ID status AS 状态, length(rows) AS 篇数
FROM "04_Projects/城市低空资源研究/参考文献/论文"
WHERE type = "paper"
GROUP BY status
SORT status ASC
```

## 全部论文

```dataview
TABLE year AS 年份, journal AS 期刊, status AS 状态, abstractStatus AS 摘要, citationKey AS 引用键
FROM "04_Projects/城市低空资源研究/参考文献/论文"
WHERE type = "paper"
SORT status ASC, year DESC
```

## 待补摘要（精读原文后补全）

```dataview
LIST
FROM "04_Projects/城市低空资源研究/参考文献/论文"
WHERE type = "paper" AND abstractStatus = "待补"
SORT year DESC
```
