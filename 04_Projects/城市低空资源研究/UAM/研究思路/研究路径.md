
- **锚定问题与主张**  
    确定唯一主线、研究问题、可证伪主张、非目标。你现在最大的风险就是“表示充分性”和“充电管理”两个主线混在一起。
    
- **文献与创新性审查**  
    系统检索 + 近邻文献对比，明确“新在哪里”。TRC 看方法新、机制新、或结论有反直觉价值，不能只换场景。
    
- **研究设计与方法冻结**  
    网络、需求、机队、SOC、充电器、策略、指标、边界全部写成可复现的协议，参数要有来源或敏感性说明。
    
- **实验设计先行**  
    情景矩阵、基线、共同随机种子、统计检验、守恒/闭合检查、停止规则都在运行前冻结，避免事后挑结果。
    
- **实现与工程验证**  
    代码 + 守恒测试 + 边界测试 + 共同随机公平性测试。你项目里 R000–R003、B2 筛查就是这层。
    
- **结果与统计推断**  
    从“机制是否可识别”到“正式 30 种子配对实验”，报告效应量、95% CI、P95/P99，而不是只看均值。
    
- **写作**  
    TRC 常见结构：`Introduction → Literature review → Model / Methodology → Solution approach → Numerical experiments → Sensitivity analysis → Conclusions`。方法与结果按证据强度写，负面结果和边界也要写。
    
- **自审与投稿循环**  
    主张审计、引用核验、格式与投稿材料、Cover Letter，然后进入审稿—返修—点对点回应。
